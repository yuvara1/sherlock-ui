# Connector brand icons

Locally bundled PNGs from provider-owned websites and official assets. Original colors and proportions are preserved; no inline SVGs, hand-drawn marks, or external image requests are used in the interface. ICO files and the official Prometheus and Grafana vector assets were rasterized for browser-independent PNG display.

The GitHub mark has a white backdrop for legibility in both themes. VictorOps uses its current Splunk branding. CloudWatch uses the official AWS Labs architecture icon.
